# Translation maintenance

Spring's `MessageSource` resolves bot texts from YAML bundles in `src/main/resources/i18n`:
`messages.yml` (English fallback), `messages_de.yml`, `messages_hr.yml`, `messages_ru.yml`.
Russian is intentionally written in Latin script.

To override individual keys without rebuilding, place bundles with the same names in an
external directory and set `HOLONET_I18N_DIRECTORY` or `holonet.i18n.directory` to its path.
For example, `config/i18n/messages_de.yml`:

```yaml
setup:
  panel:
    button: "Support öffnen"
```

Restart after editing. Existing Discord messages keep their wording; rerun `/setup` to
update the support panel. Mount the configured directory when deploying in Docker.

Plain messages pass `null` for arguments. Messages containing dynamic values use Spring's
standard `MessageFormat` placeholders (`{0}`, `{1}`); retain these when translating.
In formatted messages, write a literal apostrophe twice (`''`), as required by `MessageFormat`.
Discord's component text limits still apply to custom translations.
